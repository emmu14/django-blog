\# Django Blog Application



A blog application built using Python and Django, with article management, user authentication, and a shopping cart.



\## Features



\- User login and authentication

\- Create and view articles

\- Article detail pages

\- Image uploads

\- Shopping cart

\- Checkout and payment-success page

\- Responsive styling with CSS



\## Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- SQL / Django ORM

\- Git and GitHub



\## Project Structure



\- `articles/` — Article pages and related features

\- `accounts/` — User authentication

\- `manage.py` — Django management commands

\- `templates/` — HTML templates, if configured in this project

\- `static/` — CSS and other static assets, if configured in this project



\## Setup Instructions



1\. Clone the repository.

2\. Create and activate a Python virtual environment.

3\. Install Django and the other required dependencies.

4\. Configure environment variables and database settings.

5\. Run database migrations.

6\. Start the development server.



```bash

python manage.py migrate

python manage.py runserver

```
